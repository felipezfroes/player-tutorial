# 🎮 RPG do Zero — GameMaker

Repositório oficial da série **RPG do Zero**, do canal **FZF Productions**.

O objetivo da série é desenvolver, passo a passo, a base de um **RPG 2D top-down utilizando GameMaker e GML**, adicionando uma nova mecânica a cada episódio e explicando como ela funciona na prática.

Este repositório acompanha a evolução dos vídeos e permite acessar diferentes versões do projeto através das branches.

---

## 📺 Sobre a série

No **RPG do Zero**, construímos um RPG do início utilizando **GameMaker**.

A proposta é aprender desenvolvimento de jogos criando sistemas reais e evoluindo um único projeto ao longo dos episódios.

Entre os sistemas trabalhados na série estão:

- Movimentação top-down
- Câmera suave
- Colisão
- Sprites direcionais
- Máquina de estados
- Dash
- Inimigos
- Inteligência artificial
- Combate
- Sistema de dano
- Vida
- Knockback
- I-Frames
- Stamina
- Outros sistemas comuns de RPG

Novas mecânicas serão adicionadas conforme a série evolui.

## 🌿 Como o repositório funciona

Cada etapa importante da série possui uma **branch própria**.

Dessa forma, você pode acessar exatamente a versão do projeto correspondente àquela parte do desenvolvimento.

### Branches disponíveis

| Branch | Conteúdo |
| --- | --- |
| `ep-01-movimentacao` | Movimentação top-down |
| `ep-02-camera-suave` | Câmera suave |
| `ep-03-colisao-sprites-direcionais` | Colisão e sprites direcionais |
| `ep-04-dash` | Sistema de dash |
| `ep-06-primeiro-inimigo` | Primeiro inimigo |
| `ep-07-ia-slime` | Inteligência artificial do slime |
| `main` | Versão base do projeto |

> **Observação:** algumas branches foram criadas durante versões anteriores do planejamento da série. Por isso, a numeração das branches pode não corresponder exatamente à ordem atual dos vídeos no YouTube.

## ⬇️ Como baixar uma versão específica

Você pode selecionar a branch desejada diretamente pelo GitHub e utilizar:

**Code → Download ZIP**

Ou clonar o repositório:

```bash
git clone https://github.com/felipezfroes/player-tutorial.git
```

Depois entre na pasta:

```bash
cd player-tutorial
```

E selecione a branch desejada:

```bash
git checkout ep-01-movimentacao
```

Por exemplo, para acessar a versão com a IA do slime:

```bash
git checkout ep-07-ia-slime
```

---

## ▶️ Como abrir o projeto

1. Instale o **GameMaker**
2. Clone ou baixe este repositório
3. Escolha a branch correspondente ao conteúdo que deseja acompanhar
4. Abra o arquivo:

```
player-tutorial.yyp
```

1. Execute o projeto pelo GameMaker
