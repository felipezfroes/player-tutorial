# 🎮 RPG do Zero — GameMaker

Projeto oficial da série **RPG do Zero**, do canal **FZF Productions**.

Nesta série, desenvolvemos passo a passo a base de um RPG 2D top-down utilizando **GameMaker** e **GML**, construindo cada sistema de forma progressiva e explicando como e por que cada mecânica funciona.

O objetivo deste repositório é disponibilizar o código utilizado nos episódios e permitir que você acompanhe o desenvolvimento desde as primeiras mecânicas até sistemas mais completos de RPG.

---

## 📺 Sobre a série

**RPG do Zero** é uma série de tutoriais de GameMaker focada em construir um RPG top-down do início.

Cada episódio adiciona uma nova mecânica ao projeto, como:

- movimentação;
- câmera;
- colisão;
- sprites direcionais;
- máquina de estados;
- dash;
- inimigos;
- inteligência artificial;
- combate;
- vida e dano;
- e outros sistemas de RPG.

A ideia é que o projeto evolua junto com a série.

## 🌿 Como o repositório funciona

Cada etapa da série possui uma **branch própria**.

Isso permite baixar exatamente a versão do projeto correspondente ao conteúdo de determinado episódio.

Exemplo:

```bash
git clone https://github.com/felipezfroes/player-tutorial.git
cd player-tutorial
